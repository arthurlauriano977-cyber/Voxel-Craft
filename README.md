# Voxel-Craft

Este repositório reúne builds/open-source do Eaglercraft (versões 1.8.8 e 1.12.2) e fornece launchers web para cada versão.

Importante: o código dos submódulos permanece com as licenças originais dos upstreams. Verifique os arquivos LICENSE dentro de cada submódulo após inicializar os submódulos.

Como usar (resumo):

1. git clone https://github.com/arthurlauriano977-cyber/Voxel-Craft.git
2. git submodule update --init --recursive
3. Rode um servidor estático e abra os arquivos em launchers/1.8/ ou launchers/1.12/

Se quiser que eu integre automaticamente os builds do cliente dentro do repo (sem submódulos), diga e eu trago os conteúdos diretamente — mas por enquanto mantive como submódulos para preservar as fontes originais.
